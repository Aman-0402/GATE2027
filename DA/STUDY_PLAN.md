# GATE DA 2027 — 14-Week Study Plan

**Assumptions:** start Monday 2 Nov 2026; the first reported GATE day is 6 Feb 2027, so confirm your DA paper date on the official site. About 3 hours on weekdays and 6 on weekends (~27 hrs/week). Weights come from `DA/analysis/GATE_DA_Paper_Analysis.md` (2024 and 2026 average marks: P&S 17.5, PDSA 17, GA 15, ML 12.5, DBMS 12.5, LA 11, AI 8.5, Calculus 5).

## Daily routine
- **30 min General Aptitude** (15 marks): quant one day, verbal the next.
- **Study block:** the week's topic. Read the notes, then solve that section on the website (Practice → section) and the same section in the 2024/2026 papers.
- **15 min error log:** every wrong question, why, and the fix. Review it each Sunday.

## Phase 1 — Learn and practise (Weeks 1–10)
| Week | Focus | Do |
|---|---|---|
| 1 | Probability: counting, conditional probability, Bayes, random variables | Notes (Maths PDF), website P&S questions |
| 2 | Probability: distributions (uniform, exponential, Poisson, normal, t, χ²), CLT, tests | Past P&S questions, continue |
| 3 | Linear algebra: vector spaces, rank, systems, eigenvalues | Notes, LA questions |
| 4 | Linear algebra: projections, SVD, LU, quadratic forms + calculus (limits, Taylor, maxima/minima) | LA and Calculus questions |
| 5 | Python and basic data structures (stacks, queues, lists, trees, hash tables) | Trace code by hand daily |
| 6 | Algorithms: searching, sorting, divide and conquer, graph traversals, shortest paths | Programming/DSA questions; CS Algorithms PDF |
| 7 | Databases: ER, relational algebra, SQL, normal forms, indexing, B+ trees | DBMS questions; CS Databases PDF |
| 8 | Data warehousing: data transformation, cubes, concept hierarchies | DBMS questions |
| 9 | ML supervised: regression, ridge, logistic, kNN, naive Bayes, LDA, SVM, trees, bias-variance, cross-validation | ML notes, ML questions |
| 10 | ML: MLP/feed-forward nets, k-means, hierarchical clustering, PCA + AI search and logic | ML and AI notes |

## Phase 2 — Finish and consolidate (Weeks 11–12)
- **Week 11:** AI — adversarial search, Bayesian networks, variable elimination, sampling; then redo every wrong question from the error log.
- **Week 12:** weak sections only (check Progress on the website); one full paper per weekend, timed (3 hours).

## Phase 3 — Mock and revise (Weeks 13–14)
- **Week 13:** three timed full papers (2026, 2024, 2025 once its key is added). Mark with GATE rules (MCQ −⅓/−⅔; MSQ and NAT have no negative marking).
- **Week 14:** error-log revision, formula sheets, light practice; sleep well in the last two days.

## Tips
- Attempt every MSQ and NAT: there is no negative marking.
- Do the 10 GA questions first; they are the quickest marks.
- Many marks are in tracing Python code and in short numerical questions; practise by hand, without running code.
